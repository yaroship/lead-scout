## ⚡ О проекте

**LeadScout CLI** — инструмент для маркетологов, фаундеров и B2B-специалистов. Он позволяет за пару минут собрать чистую базу прямых контактов локального бизнеса в любом городе РФ без покупки платных API-ключей.

Скрипт не просто парсит карты — он очищает названия от рекламного мусора, отсекает федеральные сети (Додо, TopGun, OldBoy и др.), определяет тип телефонов (мобильный для мессенджеров vs городской) и генерирует готовый Excel-отчет и интерактивный HTML-дашборд.

---

## 🚀 Возможности

* 💸 **100% бесплатно и автономно:** работает напрямую, не требует платных API-ключей 2GIS или сторонних сервисов.
* 🛡️ **Фильтр франшиз:** встроенная база стоп-слов отсекает крупные сети, оставляя только частный бизнес, принимающий решения быстро.
* 📱 **Детект мобильных номеров:** автоматически разделяет мобильные телефоны (подходят для WhatsApp/Telegram) и городские линии.
* 🌐 **Сбор соцсетей и мессенджеров:** парсит прямые ссылки на Telegram, WhatsApp, VK и виджеты онлайн-записи (YClients, Dikidi).
* 🎨 **Rich Terminal UI:** стильный интерфейс с прогресс-баром, анимацией и превью-таблицей в реальном времени.
* 📊 **Мульти-экспорт:** автоматическое сохранение результатов в оформленный `.xlsx` (Excel), `.json` и автономный интерактивный `.html` дашборд.

## 📦 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/yaroship/lead-scout.git
cd lead-scout
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск
```bash
python3 app.py
```

После запуска откроется интерактивный режим: скрипт спросит город, нишу и количество страниц.

---

## 💻 Режимы запуска

### Интерактивный режим (TUI)
```bash
python3 app.py
```

### Быстрый запуск через флаги (CLI)
```bash
python3 app.py --query "детейлинг" --city "Казань" --pages 2
```

## 📁 Структура проекта

```text
lead_scout_cli/
├── app.py             # Точка входа и интерактивный Rich интерфейс
├── core/
│   ├── parser.py      # Движок сбора данных из 2GIS
│   ├── filter.py      # Фильтрация франшиз, очистка ссылок и классификатор номеров

├── output/            # Директория с выгруженными отчетами
├── requirements.txt   # Зависимости проекта
└── README.md          # Документация
```
